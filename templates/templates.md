# 提示词模板库

本文档提供 8 个即用型的提示词模板，涵盖分析、写作、编程和营销四大领域。

---

## 📊 分析类模板

### 模板 1：市场分析模板

**适用场景**：分析市场现状、竞争格局、用户需求等

```markdown
【背景】
[提供市场背景信息]

【分析维度】
请从以下维度分析 [市场/产品/竞争对手]：

1. 市场规模
   - 当前规模
   - 增长趋势
   - 预测

2. 竞争格局
   - 主要竞争对手
   - 市场份额
   - 竞争策略

3. 用户需求
   - 主要需求
   - 痛点分析
   - 发展趋势

4. 机会与威胁
   - 市场机会
   - 潜在风险
   - 应对策略

【输出格式】
Markdown 格式，每个维度 50-100 字的分析

【约束】
- 基于事实，避免过度推测
- 如果信息不确定，请标注【预测】
- 重点关注最重要的 3-5 个因素
```

---

### 模板 2：数据分析模板

**适用场景**：分析数据趋势、异常值、关键指标等

```markdown
【背景】
数据集：[数据描述]
分析目的：[你想从数据中了解什么]

【分析要求】
请对上述数据进行以下分析：

1. 趋势分析
   - 整体趋势是上升/下降/平稳？
   - 关键转折点是什么时候？
   - 预期未来 3 个月的趋势

2. 异常检测
   - 是否存在异常值？
   - 异常值的可能原因
   - 是否需要特殊处理

3. 对比分析
   - 与历史数据对比
   - 与同行业对比
   - 与预期目标对比

4. 深度洞察
   - 最重要的 3 个发现
   - 业务含义
   - 建议行动

【输出格式】
清晰的数据分析报告，包含图表描述

【数据】
[粘贴你的数据]
```

## ✍️ 写作类模板

### 模板 3：内容创作模板

**适用场景**：撰写营销文案、产品介绍、宣传内容等

```markdown
【内容目标】
内容用途：[博客/广告/社交媒体/邮件等]
目标受众：[具体描述目标用户]
核心目标：[传达什么信息/激发什么行动]

【关键信息】
必须包含的要点：
1. [要点 1]
2. [要点 2]
3. [要点 3]

避免提及：
- [应避免的信息 1]
- [应避免的信息 2]

【内容要求】
- 字数：[具体范围，如 200-300 字]
- 语气：[正式/亲切/幽默/专业 等]
- 结构：[开头/中间/结尾 应该怎样]
- 行动号召 (CTA)：[希望用户做什么]

【参考示例】
[粘贴一篇你喜欢的类似内容作为参考]

【输出格式】
直接给出最终文案，无需解释
```

**适用场景**：生成代码片段、函数、脚本等

```markdown
【任务描述】
编程语言：[Python/JavaScript/Java 等]
框架/库：[如适用]
功能需求：[具体描述需要实现什么功能]

【输入输出】
输入：
[描述输入数据的格��和类型]

输出：
[描述预期的输出格式]

【具体需求】
1. [功能需求 1]
2. [功能需求 2]
3. [功能需求 3]

【约束条件】
- 错误处理：[需要处理哪些错误]
- 性能要求：[是否有性能要求]
```

### 模板 6：代码审查模板

**适用场景**：审查代码质量、找出潜在问题等

```markdown
【代码审查】
编程语言：[Python/JavaScript 等]
代码目的：[这段代码做什么]

【审查维度】
请从以下维度审查代码：

1. 功能性
   - 代码是否正确实现了预期功能？
   - 是否存在逻辑错误？
   - 边界情况是否处理妥当？

2. 可读性
   - 变量名是否有意义？
   - 函数是否足够简洁？
   - 是否需要添加注释？

3. 性能
   - 是否存在明显的性能问题？
   - 时间复杂度和空间复杂度如何？
   - 是否有优化空间？

4. 安全性
   - 是否存在潜在的安全漏洞？
   - 是否正确处理用户输入？
   - 是否有内���泄漏风险？

5. 最佳实践
   - 是否遵循编程规范？
   - 是否使用了最适合的数据结构？
   - 是否有更好的实现方式？

【输出格式】
为每个发现提供：
- 发现的问题
- 为什么这是问题
- 改进建议
- 优先级（高/中/低）

【代码】
[粘贴你的代码]
```

## 📈 营销类模板

### 模板 7：营销策略规划模板

**适用场景**：制定营销策略、优化转化、运营规划等

```markdown
【营销背景】
产品/服务：[产品名称和简介]
目标用户：[具体描述]
营销目标：[KPI 和具体目标]
营销预算：[预算范围]
时间周期：[多长时间内要达成目标]

【市场分析】
目标市场规模、竞争情况、用户需求等

【营销策略】
请从以下方面制定营销策略：

1. 定位与差异化
   - 产品的独特卖点
   - 目标用户画像
   - 竞争对手分析

2. 营销渠道
   - 内容营销
   - 付费广告
   - 社交媒体
   - 公关合作
   - 其他渠道

3. 内容策略
   - 内容类型
   - 内容主题
   - 发布频率
   - 用户转化路径

4. 转化优化
   - 关键转化节点
   - 优化策略
   - 预期效果

5. 度量与优化
   - KPI 指标
   - 追踪方式
   - 优化周期
   - 改进机制

【执行计划】
- 周期分解（第 1 周-第 4 周 的具体行动）
- 资源分配
- 责任人

【预期结果】
- 预期转化率/销售额
- 投资回报率 (ROI)
- 成功标准

【输出格式】
详细的营销计划书，包含上述所有要素
```

### 模板 8：用户反馈分析模板

**适用场景**：分析用户评论、问卷反馈、社交媒体评论等

```markdown
【背景】
数据来源：[用户评论/问卷/社交媒体等]
时间范围：[什么时候收集的]
数据量：[多少条反馈]
产品/服务：[关于什么产品]

【分析任务】
请分析用户反馈数据：

1. 情感分析
   - 正面反馈的比例
   - 负面反馈的主要内容
   - 中立反馈包含什么信息

2. 主题归类
   - 反馈的主要主题是什么
   - 各个主题的频率
   - 主题之间的关联

3. 问题识别
   - 用户最主要的痛点
   - 最常提到的问题
   - 问题的根本原因

4. 满意度分析
   - 整体满意度评分
   - 满意度的主要驱动因素
   - 改进最需要关注的方面

5. 改进建议
   - 优先级最高的改进方向
   - 具体的改进建议
   - 预期效果

【输出格式】
结构清晰的分析报告，包含：
- 执行摘要
- 详细发现
- 改进建议
- 优先级排序

【数据】
[粘贴用户反馈数据]
```

## 🚀 如何使用这些模板

### 步骤 1：选择合适的模板
根据你的任务选择对应的模板

### 步骤 2：填充模板
用你的具体信息替换 [括号中的内容]

### 步骤 3：测试和优化
- 第一次运行看看效果
- 如果结果不理想，调整提示词
- 收集有效的提示词变体

### 步骤 4：建立个人库
保存你优化过的提示词版本，建立个人的提示词库

## 💡 模板使用技巧

### 技巧 1：组合使用
多个模板可以组合使用。例如：
- 先用模板 2（数据分析）分析趋势
- 再用模板 7（营销策略）制定策略

### 技巧 2：自定义修改
这些都是通用模板，应该根据你的具体需求修改：
- 添加或删除某些维度
- 调整要求的细节
- 增加特定的约束

### 技巧 3：嵌套使用
在一个提示词中嵌套多个子任务。例如：
```
首先做 [任务 A]
然后基于 [任务 A] 的结果做 [任务 B]
最后综合两个结果给出 [最终建议]
```

### 技巧 4：迭代优化
每次使用时记录：
- 哪部分效果好
- 哪部分需要改进
- 下次怎���调整
经过几次迭代，你会得到最适合你的模板版本
