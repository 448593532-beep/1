# 提示词库 (Prompt Library)

这是一个专业的提示词（Prompt）知识库和模板集合，包含各类场景下的高效提示词设计、最佳实践和实际案例。

## 📁 项目结构

```
├── README.md                    # 项目说明
├── prompts.md                   # 核心提示词文档
├── best-practices.md            # 最佳实践指南
├── templates/                   # 提示词模板
│   ├── analysis-template.md     # 分析类提示词
│   ├── writing-template.md      # 写作类提示词
│   ├── code-template.md         # 编程类提示词
│   └── marketing-template.md    # 营销类提示词
└── examples/                    # 实际案例
    ├── hotel-keywords.md        # 酒店关键词分析案例
    └── other-cases.md           # 其他案例
```

## 🎯 快速开始

### 提示词基础
- **什么是提示词**：引导 AI 生成所需输出的指令或问题
- **核心作用**：提高 AI 输出的质量、准确性和相关性

### 五大核心要素
1. **背景信息** - 提供上下文
2. **任务描述** - 清楚的目标
3. **输出格式** - 期望的结果格式
4. **具体要求** - 细节限制
5. **示例** - 展示期望效果

## 📖 主要内容

| 文件 | 描述 |
|------|------|
| `prompts.md` | 完整的提示词基础知识和核心概念 |
| `best-practices.md` | 高效提示词的最佳实践和优化技巧 |
| `templates/` | 各类场景的提示词模板（分析、写作、编程、营销） |
| `examples/` | 真实案例演示，包括酒店关键词分析等 |

## 💡 核心原则

✅ **清晰具体** - 避免模糊表述  
✅ **角色定位** - 明确 AI 的身份和专业背景  
✅ **格式约定** - 指定输出格式（表格、JSON、Markdown 等）  
✅ **分步骤** - 复杂任务分解为多个步骤  
✅ **设置约束** - 限制字数、数量、范围等
