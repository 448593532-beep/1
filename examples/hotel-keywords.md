# 实际案例：定州酒店关键词分析

本文档展示了一个**完整的提示词优化迭代过程**，以定州酒店关键词分析为例。

## 📚 案例背景

**场景**：某 OTA 平台需要优化定州市酒店预订页面的搜索关键词  
**目标**：了解用户的搜索习惯，优化平台的搜索推荐和广告投放  
**挑战**：如何设计一个高效的提示词来获得有价值的关键词数据

---

## 版本迭代过程

### 第一版：初始提示词（❌ 效果很差）

```markdown
分析定州酒店的关键词
```

#### 问题分析
| 问题 | 影响 |
|------|------|
| 没有明确的任务描述 | AI 无法理解具体需求 |
| 缺少背景和上下文 | 可能返回无关信息 |
| 没有指定输出格式 | 输出杂乱无章 |
| 没有数量或质量限制 | 输出过多或过少 |

#### AI 可能的输出
```
定州酒店的关键词包括：酒店、预订、住宿、房间、服务...
（太笼统，没有实用价值）
```

#### 评分
- 完整性：⭐ (1/5)
- 实用性：⭐ (1/5)
- 可用性：⭐ (1/5)

---

### 第二版：改进后提示词 (🟡 效果一般)

```markdown
请分析定州市酒店预订平台的搜索关键词。

需要包括：
1. 最常用的搜索词
2. 根据酒店类型分类（如星级、地理位置、特色等）
3. 按热度排序

返回 Markdown 表格格式。
```

#### 改进点
| 改进 | 说明 |
|------|------|
| ✅ 明确了地点 | 定州市，而不是全国 |
| ✅ 指定了应用场景 | OTA 预订平台 |
| ✅ 明确了分类维度 | 星级、地理位置、特色 |
| ✅ 指定了输出格式 | Markdown 表格 |

#### 仍存在的问题
| 问题 | 影响 |
|------|------|
| 没有角色定位 | AI 的专业性可能不足 |
| 没有具体数量要求 | 输出可能过多或过少 |
| 没有提供示例 | AI 可能理解错误 |
| 缺少质量标准 | 难以评估输出质量 |

#### AI 可能的输出
```markdown
| 关键词 | 类型 | 热度 |
|------|------|------|
| 定州酒店 | 基础词 | 高 |
| 定州五星酒店 | 星级词 | 中 |
| 定州火车站附近酒店 | 位置词 | 中 |
| 定州亲子酒店 | 特色词 | 低 |
...

（输出格式对，但仍缺乏深度分析）
```

#### 评分
- 完整性：⭐⭐⭐ (3/5)
- 实用性：⭐⭐ (2/5)
- 可用性：⭐⭐⭐ (3/5)

### 第三版：优化后提示词 (✅ 效果很好)

```markdown
【背景】
定州市是河北省重要的旅游城市，随着旅游业发展，
酒店预订需求不断增加，用户搜索行为多样化。

【角色】
你是一位有 8 年 OTA（在线旅行社）平台经验的市场数据分析师，
专长于酒店行业的用户搜索行为分析和关键词优化。

【任务】
分析定州市酒店预订平台的高频搜索关键词，
并从用户搜索意图的角度进行深度解读。

【需求】
1. 列出 15 个代表性的搜索关键词
2. 按以下三个维度进行分类：
   - 基础词（3-5 个）：最通用的搜索词
   - 修饰词（5-7 个）：带有特定属性的词
   - 需求词（3-5 个）：反映具体业务需求的词

3. 对每个关键词进行标注：
   - 用户搜索意图（信息搜索/需求搜索）
   - 竞争程度（低/中/高）
   - 市场机会评估（待开发/有潜力/高价值）

【输出格式】
返回 Markdown 表格，包���以下列：
| 分类 | 关键词 | 搜索意图 | 竞争度 | 市场评估 | 用户画像 |

【示例】
请参考以下高质量示例的格式：

| 分类 | 关键词 | 搜索意图 | 竞争度 | 市场评估 | 用户画像 |
|-----|------|--------|------|--------|--------|
| 基础词 | 定州酒店 | 信息搜索 | 高 | 高价值 | 宽泛用户，刚产生需求 |
| 基础词 | 定州住宿 | 信息搜索 | 高 | 高价值 | 宽泛用户，意向不明确 |
| 修饰词 | 定州五星酒店 | 需求搜索 | 中 | 有潜力 | 高端用户，有明确需求 |
| 修饰词 | 定州经济型酒店 | 需求搜索 | 中 | 高价值 | 预算有限用户，对价格敏感 |
| 修饰词 | 定州火车站附近酒店 | 需求搜索 | 中 | 有潜力 | 车站来客，需要便利位置 |
| 需求词 | 定州亲子酒店 | 需求搜索 | 低 | 有潜力 | 家庭游客，需要儿童设施 |
| 需求词 | 定州商务酒店 | 需求搜索 | 中 | 高价值 | 出差商人，需要会议设施 |

【约束条件】
- 仅列出中文关键词
- 关键词应该是真实存在的搜索用语
- 避免品牌词（如具体酒店名称"希尔顿""万豪"）
- 排除过于生僻或不相关的词汇
- 确保信息的准确性和实用性

【额外信息】
如果可能，请为每个关键词提供一句简要说明，
解释为什么这个关键词对平台很重要。

【输出要求】
- 直接返回表格，无需冗长的前言或解释
- 表格应该清晰易读，可以直接用于决策
```

#### 改进点分析
| 改进方面 | 具体改进 |
|---------|---------|
| **背景信息** | 详细的市场背景，帮助 AI 理解上下文 |
| **角色定位** | 明确的专业身份和经验年限 |
| **具体维度** | 分类清晰，每类明确数量范围 |
| **质量标准** | 多维度评估（意图、竞争度、市场评估） |
| **参考示例** | 7 个示例，清晰展示期望格式 |
| **约束条件** | 5 个明确的限制条件 |
| **输出规范** | 明确指示输出格式和风格 |

```
版本 1（过于简化）
  ↓

版本 2（基础优化）
  ↓

```

## 关键优化要点

### ✅ 使版本 1 → 版本 3 改进最大的因素

1. **添加背景信息** (+30%)
   - 帮助 AI 理解市场环境
   
2. **明确角色定位** (+20%)
   - AI 采用专业视角分析
   
3. **提供参考示例** (+25%)
   - 示例抵得上千言万语
   
4. **设置明确约束** (+15%)
   - 防止输出偏离预期
   
5. **指定输出格式** (+10%)
   - 确保结果可直接使用
